# セッション要約

このセッションの会話を分析し、構造化された要約を作成してください。

## 出力フォーマット

以下の形式で要約を出力してください：

### セッション概要
- **日付**: [今日の日付]
- **プロジェクト/コンテキスト**: [会話から推測]

### 完了した作業
主な成果をリストアップ：
- [成果1]
- [成果2]
- ...

### 決定事項
セッション中に行った重要な決定：
- [決定1とその理由]
- [決定2とその理由]
- ...

### 解決した問題
解決したバグや課題：
- [問題と解決策]
- ...

### 変更したファイル
作成・変更・削除したファイル：
- [ファイルパス]: [変更内容]
- ...

### 次のステップ
次にやるべきこと：
- [ ] [次のステップ1]
- [ ] [次のステップ2]
- ...

### 残っている課題
未解決の質問や今後の検討事項：
- [質問1]
- ...

---

簡潔だが包括的に。将来の自分や他の人がこのセッションで何が起きたか理解できる、実用的な情報に焦点を当ててください。
